# Packer

A small archive utility in ruby.

## Functionality

- print out the list of files contents, and their total uncompressed size
- print out archive size
- compress
- encrypt using passphrase

## Compression Backends

- zip
- bz2
- 7z
- ouch
- xz
- zstd
- atool

## Encryption Backends

- kryptor
- age
- gpg
- picocrypt

## Information Backends

- tree
- du / gdu -h
